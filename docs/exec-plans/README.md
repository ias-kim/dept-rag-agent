# exec-plans

작업 하나 = 파일 하나. 시작할 때 `active/<YYYY-MM-DD>-<주제>.md`로 만들고, 끝나면 `done/`으로 옮긴다.

## 템플릿

```markdown
# <주제>

- 담당: <이름> · 시작: YYYY-MM-DD · 관련 주차: N주차

## 목표
한두 문장.

## 완료 기준 (reviewer가 이걸로 판정한다)
- [ ] 검증 가능한 조건 1 (예: `make check` 통과, 테스트 X가 Y를 검증)
- [ ] ...

## 범위 밖
-

## 결정 로그
- YYYY-MM-DD: 무엇을 왜 결정했는지
```
