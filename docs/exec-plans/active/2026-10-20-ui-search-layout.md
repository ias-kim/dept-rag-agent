# 질문 화면 B안(검색형) 리디자인 + 내 정보 API

- 담당: 김성관 · 시작: 2026-10-20 · 관련 주차: 5주차 (M4a 후속)

## 목표
M4a 화면이 직관적이지 않고 글자 간격이 불편하다는 피드백에 따라, 브레인스토밍에서 고른 B안(검색형)으로 로그인·질문 화면을 다시 꾸민다. 상단에 수강 과목을 보여 주기 위해 `GET /api/me`를 추가한다.
목업: 로컬 `.superpowers/brainstorm/…/mockups/b-search.html` (보고서 폴더에 PNG 사본).

## 완료 기준 (reviewer가 이걸로 판정한다)
- [ ] `GET /api/me` → `{username, courses(정렬된 목록)}`. 토큰 없으면 401, 한도 차감 없음, 수강 변경이 재로그인 없이 반영 — `tests/db/test_api.py`
- [ ] OpenAPI 스냅샷 갱신(`make generate`)
- [ ] 질문 화면: 큰 제목·한 줄 설명·큰 검색창·예시 질문(누르면 입력창 채움)·글자 수, 답변 카드(본문 [n] 배지), "이 답변의 근거 자료" 목록(번호·PDF·파일명·절·"N쪽"), 안내 띠, 대기 중 스켈레톤
- [ ] 상단: 아이디 + 수강 과목 배지(없으면 "게스트 · 학사 자료만"), 로그아웃. `/api/me` 실패는 배지만 숨기고 질문은 계속 가능
- [ ] 로그인 화면 같은 디자인 체계로
- [ ] 글꼴 Pretendard(npm 패키지로 번들, 외부 CDN 없음), 줄간격 1.7, `word-break: keep-all`, 모바일 폭 한 단
- [ ] 기존 불변 조건 유지: 출처 순서·번호, 재제출 차단, 401 만료 처리, 공지 코드 숨김 — 기존 테스트를 새 표시 형식에 맞게 고치되 단언 의미는 유지
- [ ] `make check` 통과, dev-note(frontend·auth-api) 갱신, 브라우저로 확인
