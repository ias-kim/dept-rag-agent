## 결정 로그
- 2026-11-06: 스파이크 S3 — `iam simulate-principal-policy`에서 `iam:CreateRole`·`iam:PassRole`·`ec2:RunInstances`·`cloudformation:CreateStack` 모두 allowed. 시뮬레이션만으로 SCP까지 확정할 수 없어 실제 스택 생성을 최종 증거로 삼는다.
- 2026-11-06: 리전은 명령마다 명시한다 — CLI 기본값에 기대면 다른 리전에 자원이 생긴다.
- 2026-11-06: 도메인은 일단 `<IP>.sslip.io` — DuckDNS는 사람의 계정·토큰이 필요하다. Caddy는 `DOMAIN` 값만 쓰므로 나중에 값만 바꾸면 옮겨 갈 수 있다(설계 결정 12와 다름, 설계 §7 정정).
- 2026-11-06: 색인은 재적재하지 않고 로컬 `documents`·`chunks` 데이터만 복원한다 — 임베딩 비용이 없고 평가와 같은 색인이 된다. `users`·`usage_daily`는 옮기지 않고 서버 계정을 새로 만든다.
- 2026-11-06: 배포는 `git pull` 대신 `git archive`로 커밋 하나를 올린다 — 서버에 git 자격이 필요 없고 병합 전 브랜치도 같은 방법으로 확인할 수 있다.
- 2026-11-06: AMI ID는 SSM 최신값 대신 파라미터로 고정한다 — 최신값을 쓰면 스택 갱신 때 인스턴스가 교체되어 DB 볼륨이 사라질 수 있다.
