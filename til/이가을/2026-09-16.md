# 2026-09-16

## 프로젝트 소개 — 학과 지식 질의응답 AI 에이전트

- 서비스 개요: 학생이 질문하면 AI가 학과 자료를 찾아본 뒤 근거와 함께 답해 주는 서비스
- AI가 아는 대로 답하면 없는 규정을 지어낼 수 있어(환각), 우리 자료를 먼저 찾아본 뒤 그 내용만으로 답하게 하는 방식을 택함 → 검색 증강 생성(RAG)
- 전공자료(AI Agent 교과목 강의자료 중심, 수강생 한정)와 학사 공지·학사일정(전체 공개) 두 종류를 함께 다룸
- 자료마다 공개 범위가 다르므로 검색 단계에서부터 나눠 다루도록 설계

## 이번 주 목표

- 에이전트 동작 구조를 설계 단계부터 함께 확인

## 소감

RAG 개념을 왜 써야 하는지 막연히 알고 있었는데, 환각 문제와 자료별 공개 범위 이슈를 직접 정리해보니 설계 단계에서부터 검색 흐름을 나눠 고민해야 하는 이유가 확실히 이해됐다. 앞으로 에이전트 동작 구조를 설계할 때도 이런 식으로 문제부터 짚고 가면 훨씬 수월할 것 같다.
