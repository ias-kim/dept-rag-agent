## 2026-09-23

오늘은 RAG 기반 AI 시스템에서 실제로 필요한 데이터 전처리 흐름을 배웠다. 단순히 문서를 넣는 것만으로는 AI가 정확한 답을 내기 어렵고, 자료를 수집하고 정리하며 분할하고 출처를 남기는 과정이 매우 중요하다는 점이 인상 깊었다.

- 자료 수집: 강의자료, 시간표, 공지사항 등을 한곳에 모아야 AI가 학과 정보를 정확하게 이해할 수 있다.
- 전처리: 학교명, 교수명, 쪽번호 같은 중복 정보는 제거해야 검색 품질이 좋아진다.
- 문서 분할: 큰 문서를 작은 단위로 나누어 질문에 맞는 정보를 빠르게 찾을 수 있다.
- 메타데이터: 문서의 출처와 과목 정보를 남겨야 근거를 확인할 수 있다.
- 임베딩: 의미 기반으로 유사 문서를 찾을 수 있어 질문과 비슷한 내용을 효과적으로 추출할 수 있다.

이 과정을 통해 AI는 단순히 단어를 이어 붙이는 도구가 아니라, 실제 자료를 근거로 답하는 도구로 발전할 수 있다는 점을 배웠다. 앞으로 프로젝트를 진행할 때도 자료의 정리와 구조화가 가장 중요하다는 점을 꼭 기억해야겠다.

### 후기
처음엔 단순한 문서 정리처럼 느껴졌지만, 실제로는 AI의 답변 품질을 좌우하는 핵심 단계라는 걸 알게 되었다. 특히 출처와 의미 기반 검색이 중요하다는 점이 가장 인상 깊었다. 앞으로 학과 정보 AI를 만들 때 이 흐름을 기준으로 설계하면 더 신뢰도 높은 결과를 얻을 수 있을 것 같다.
