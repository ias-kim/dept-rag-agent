## 2. 문제 풀이
### 문제 1. Course 클래스 만들기

과목 이름과 점수 목록을 저장하고 평균을 반환하는 `average()` 메서드를 작성했다.

```python
class Course:
    def __init__(self, name, scores):
        self.name = name
        self.scores = scores

    def average(self):
        return sum(self.scores) / len(self.scores)


course = Course("Python", [80, 90, 100])
print(course.average())
```

### 문제 2. PassFailCourse 클래스 만들기

`Course` 클래스를 상속받아 평균이 60점 이상이면 `"PASS"`를 반환하도록 작성했다.

```python
class PassFailCourse(Course):
    def result(self):
        if self.average() >= 60:
            return "PASS"
        return "FAIL"


course = PassFailCourse("Python", [80, 90, 100])
print(course.result())
```
