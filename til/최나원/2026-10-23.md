## 1. 예외처리

- `try`는 오류가 발생할 수 있는 코드를 실행한다.
- `except`는 오류가 발생했을 때 처리할 코드를 작성한다.
- `finally`는 오류 발생 여부와 관계없이 실행할 코드를 작성한다.
- `raise`는 원하는 오류를 직접 발생시킨다.

```python
def to_score(text):
    try:
        return int(text)
    except ValueError:
        return None

print(to_score("85"))
print(to_score("팔십오"))
```

## 2. 컴프리헨션

- 컴프리헨션은 반복문과 조건문을 사용해 새로운 리스트나 딕셔너리를 간단하게 만드는 방법이다.
- 리스트 컴프리헨션은 `[표현식 for 변수 in 목록 if 조건]` 형태로 작성한다.

```python
scores = [85, 42, 92, 58, 77]

passed = [s for s in scores if s >= 60]
print(passed)

result = {
    s: ("PASS" if s >= 60 else "FAIL")
    for s in scores
}
print(result)
```

## 3. with open

- `with open()`은 파일을 열고 작업이 끝나면 자동으로 닫아 준다.
- `encoding="utf-8"`은 한글이 깨지지 않도록 파일을 읽을 때 사용한다.

```python
with open("scores.txt", encoding="utf-8") as f:
    lines = f.read().splitlines()

print(lines)
```

## 4. 실습 문제 풀이

### 문제 1. 숫자가 아닌 줄 건너뛰기

```python
scores = []
skipped = 0

with open("scores.txt", encoding="utf-8") as f:
    for line in f:
        try:
            scores.append(int(line.strip()))
        except ValueError:
            skipped += 1

if scores:
    print("평균:", sum(scores) / len(scores))
else:
    print("점수가 없습니다.")

print("건너뛴 줄:", skipped)
```

### 문제 3. 과목별 PDF 파일 이름 출력하기

```python
from pathlib import Path

def collect(root):
    try:
        folders = [
            p for p in Path(root).iterdir()
            if p.is_dir()
        ]
    except FileNotFoundError:
        print(f"{root} 폴더가 없습니다.")
        return []

    return [
        (folder.name, sorted(
            p.name for p in folder.glob("*.pdf")
        ))
        for folder in folders
    ]

for code, files in collect("data/major"):
    print(code, files)
```

## 5. 어려웠던 점

- 컴프리헨션은 한 줄에 반복문과 조건문이 들어가 처음에는 이해하기 어려웠다.
- `try-except`를 사용해 오류가 발생해도 프로그램이 멈추지 않도록 처리하는 부분이 헷갈렸다.
- 예제를 직접 작성하고 실행하면서 각 문법의 역할을 이해할 수 있었다.
