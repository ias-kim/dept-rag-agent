
## 1. 오늘 배운 것

- RAG는 AI가 기억에만 의존해서 답변하는 것이 아니라, 필요한 자료를 먼저 찾아보고 그 자료를 바탕으로 답변하는 방식이다.
- RAG는 자료를 작은 조각으로 나누어 저장하고, 사용자의 질문과 관련된 자료를 찾아 답변에 활용한다.
- RAG를 사용하면 답변의 근거가 되는 자료의 출처도 함께 표시할 수 있다.
- MCP는 AI가 여러 가지 도구를 쉽게 사용할 수 있도록 도와주는 표준 규격이다. 도구의 이름, 설명, 입력값을 일정한 형식으로 정리한다.
- 우리 프로젝트에서는 MCP를 사용하여 학사 검색과 전공 검색 기능을 연결하였다.
- 실제 서비스에서는 단순히 글자가 같은지 찾는 것이 아니라 의미가 비슷한 자료를 찾는 임베딩 기술을 사용한다.

## 2. 실습 문제 풀이

### 문제 1: RAG를 활용한 자료 검색

```python
cards = [
    {"쪽": 20, "내용": "2학년 일본어 특강 월~목 8~9교시"},
    {"쪽": 2, "내용": "일본어 특강 장소 304호"},
    {"쪽": 5, "내용": "추석 연휴 강의실 폐쇄"},
]

question = "추석"

found = [c for c in cards if question in c["내용"]]

print(found)
print([c["쪽"] for c in found])
```

리스트 안에 딕셔너리 형태로 자료를 저장하고, 질문에 해당하는 내용이 있는지 검색하는 코드이다. `for`를 사용하여 자료를 하나씩 확인하고, 질문과 일치하는 내용이 있으면 결과에 저장한다. 실행하면 추석과 관련된 자료와 쪽수인 `5`가 출력된다.

### 문제 2: MCP 도구 정보 작성하기

```python
tool = {
    "name": "search_academic",
    "description": "학사 공지·시간표에서 찾기",
    "input": {"query": "검색어(문자열)"}
}

print(tool["name"], "-", tool["description"])
```

딕셔너리를 사용하여 MCP 도구의 이름, 설명, 입력값을 저장하는 코드이다. 키를 이용하면 필요한 정보를 쉽게 가져올 수 있다. 실행하면 `search_academic - 학사 공지·시간표에서 찾기`가 출력된다.

## 3. 어려웠던 것

RAG와 MCP의 차이점을 이해하는 것이 처음에는 조금 어려웠다. RAG는 질문과 관련된 자료를 찾아 답변하는 방식이고, MCP는 AI가 여러 도구를 일정한 형식으로 사용할 수 있도록 연결해 주는 규격이라는 점을 정리하면서 차이를 이해했다. 또한 리스트 안에 딕셔너리를 넣어 자료를 검색하는 코드도 다시 살펴보았다.

## 4. 느낀점

이번 시간에는 RAG와 MCP의 개념을 새롭게 배웠다. 특히 RAG가 AI의 답변에 필요한 자료를 직접 찾아 활용한다는 점이 인상 깊었다. 실습을 통해 이전에 배웠던 리스트와 딕셔너리가 실제 프로젝트에서도 사용된다는 것을 알게 되었다. MCP 역시 도구를 일정한 형식으로 연결하여 사용할 수 있다는 점을 이해했다. 앞으로도 파이썬에서 배운 문법들이 실제 프로젝트에서 어떻게 활용되는지 관심을 가지고 공부해야겠다고 느꼈다.
