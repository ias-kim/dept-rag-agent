# 최나원 TIL

## 1. 오늘 배운 것

- 리스트는 여러 값을 순서대로 담고, 값을 추가하거나 바꿀 수 있다. 예를 들어 `scores = [85, 92, 78]`처럼 만들고 `scores.append(90)`으로 값을 추가한다.
- 튜플은 리스트처럼 순서가 있지만, 만든 뒤 값을 바꿀 수 없다. 좌표처럼 바뀌면 안 되는 값을 묶을 때 쓸 수 있다.
- 딕셔너리는 키와 값으로 정보를 저장한다. `student["name"]`처럼 이름표인 키를 사용해 필요한 값을 찾는다.
- 집합은 같은 값을 한 번만 저장한다. 중복을 없애거나 두 집합에 함께 있는 값을 찾을 때 편리하다.
- 프로젝트에서도 딕셔너리는 자료 조각의 출처 같은 정보를 담고, 집합의 교집합은 요청한 과목과 실제 수강 과목을 비교하는 데 쓰인다.

## 2. 실습 문제 풀이

### 문제 1: 과목별 점수와 평균

```python
scores = {
    "파이썬": 90,
    "수학": 85,
    "영어": 95,
}

total = 0
for subject, score in scores.items():
    print(f"{subject}: {score}")
    total += score

average = total / len(scores)
print(f"평균: {average}")
```

딕셔너리의 `items()`를 사용하면 과목 이름과 점수를 함께 꺼낼 수 있다. 점수를 모두 더한 뒤 과목 수로 나누면 평균이 나온다. 이 예시의 평균은 `90.0`이다.

### 문제 2: 리스트에서 중복 없애기

```python
numbers = [1, 2, 2, 3, 3, 3]
unique_numbers = set(numbers)

print(unique_numbers)       # {1, 2, 3}
print(len(unique_numbers))   # 3
```

리스트를 집합으로 바꾸면 중복된 숫자가 하나씩만 남는다. 따라서 중복을 없앤 값의 개수는 `3`이다.

## 3. 어려웠던 것

딕셔너리에서 과목 이름과 점수를 함께 꺼내는 방법과 점수의 합계·평균을 계산하는 순서를 처음에는 헷갈릴 수 있다. `items()`로 한 쌍씩 꺼내고, 반복할 때마다 점수를 더한 뒤 전체 개수로 나누는 방법으로 정리했다.

## 4. 느낀점

자료형마다 잘하는 일이 다르다는 점을 배웠다. 리스트와 튜플은 순서대로 모을 때, 딕셔너리는 이름으로 값을 찾을 때, 집합은 중복을 없앨 때 쓰면 된다는 것을 실습 코드로 확인했다. 프로젝트에서도 이 자료형들이 실제 기능에 사용된다는 점이 흥미로웠다.
