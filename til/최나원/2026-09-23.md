## 1. 오늘 배운 것
여러 값을 묶어 다루는 파이썬 자료형 4가지를 배움
리스트(list): 순서가 있고 바꿀 수 있는 목록. scores = [85, 92, 78], scores.append(90)으로 추가
튜플(tuple): 순서는 있지만 바꿀 수 없는 목록. point = (3, 5)에서 point[0] = 10을 하면 에러
딕셔너리(dict): 이름표(키)로 값을 찾는 묶음. student["name"]처럼 사용
집합(set): 중복이 없는 모음. 중복 제거와 교집합(&)에 사용
상황별로 고르는 기준
순서대로 여러 값 + 추가·삭제 필요 → 리스트
순서대로 여러 값 + 바뀌면 안 됨 → 튜플
이름으로 찾기 → 딕셔너리
중복 제거·교집합 → 집합
우리 프로젝트에서도 실제로 쓰인다는 것을 알게 됨
자료 조각의 꼬리표(source, page 등)가 딕셔너리 모양
서버가 "요청한 과목 ∩ 실제 수강 과목"을 집합 교집합으로 계산해 권한 밖 과목을 걸러냄

# 문제 1: 딕셔너리로 과목 점수 출력 + 평균
scores = {"파이썬": 85, "자료구조": 92, "데이터베이스": 78}

total = 0
for subject, score in scores.items():
    print(f"{subject}: {score}")
    total += score

print("평균:", total / len(scores))   # 85.0

# 문제 2: 집합으로 중복 제거 후 개수 구하기
nums = [1, 2, 2, 3, 3, 3]
print(len(set(nums)))   # 3
