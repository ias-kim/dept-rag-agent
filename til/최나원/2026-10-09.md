## 2026-10-09 TIL

## ## 1. 오늘 배운 것

* 파이썬 REPL을 사용하여 코드를 한 줄씩 실행하고 결과를 확인하는 방법을 배움
* 예시: `print("Hello, World!")`를 입력하자마자 화면에 바로 출력되는 것을 확인해 봄
* 변수와 자료형에 대해 배우면서 정수형(`int`), 실수형(`float`), 문자열(`str`), 불리언(`bool`)의 차이를 이해함
* 예시: 나이를 저장하는 `age = 20`은 정수형, 키를 저장하는 `height = 175.5`는 실수형이라는 것을 알게 됨
* 연산자의 사용법과 조건문(`if`), 반복문(`while`, `for`)의 기본 사용법을 배움
* 예시: `if score >= 80:`을 사용해 점수가 80점 이상일 때 "합격"을 출력하는 조건문을 만들어 봄
* 문자열의 인덱싱과 슬라이싱, `f-string`을 사용하여 문자열을 다루는 방법을 배움
* 예시: `f"내 이름은 {name}이고 나이는 {age}살입니다."`처럼 변수를 문자열 안에 쉽게 쏙 넣는 방법을 실습함

## ## 2. 어려웠던 것

* 파이썬의 자료형과 연산자를 이해하고 조건문과 반복문을 사용하는 것이 처음에는 복잡하고 어려웠음
* 예시: `for` 문과 `while` 문의 차이점이나, 코드가 반복될 때 헷갈리는 부분이 많았음
* 각 문법을 언제, 어떤 상황에서 사용해야 하는지 명확하게 구분하는 데 어려움을 느낌

## ## 3. 해결책 또는 시도한 것

* REPL에서 코드를 직접 여러 번 입력하고 곧바로 실행하면서 결과를 눈으로 확인함
* 예시: 에러가 나면 어떤 부분이 틀렸는지 문법을 수정해 가며 원인을 찾아봄
* 변수와 자료형 변환을 직접 연습해 보고, 조건문과 반복문 예제 코드를 손으로 직접 작성해보면서 감을 익히려고 노력함

## ## 4. 느낀점

* 오늘 파이썬의 기본 문법을 배우면서 코드를 직접 작성하고 컴퓨터가 실행하는 과정을 눈으로 직접 익힐 수 있어서 신기하고 흥미로웠음
* 처음에는 코드와 문법이 낯설고 어려운 부분도 많았지만, 직접 예제를 입력하고 결과를 확인해 보니 조금씩 이해가 되면서 자신감이 생겼음
* 앞으로도 오늘 배운 내용들을 잊지 않도록 반복해서 연습하고, 더 다양한 예제를 만들어보며 파이썬 기초 문법을 확실히 내 것으로 만들고 싶다는 생각이 들었음
