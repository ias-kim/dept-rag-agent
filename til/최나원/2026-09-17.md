## 1. 오늘 배운 것

- 파이썬 REPL을 사용하여 코드를 한 줄씩 실행하고 결과를 확인하는 방법을 배움
- 변수와 자료형에 대해 배우면서 정수형(int), 실수형(float), 문자열(str), 불리언(bool)의 차이를 이해함
- 연산자의 사용법과 조건문(if), 반복문(while, for)의 기본 사용법을 배움
- 문자열의 인덱싱과 슬라이싱, f-string을 사용하여 문자열을 다루는 방법을 배움

## 2. 어려웠던 것

- 파이썬의 자료형과 연산자를 이해하고 조건문과 반복문을 사용하는 것이 어려웠음
- 각 문법을 언제 사용해야 하는지 구분하는 데 어려움을 느낌

## 3. 해결책 또는 시도한 것

- REPL에서 코드를 직접 입력하고 실행하면서 결과를 확인함
- 변수와 자료형 변환을 연습하고 조건문과 반복문 예제를 직접 작성해보면서 문법을 익히려고 노력함

## 4. 느낀점

- 오늘 파이썬의 기본 문법을 배우면서 코드를 작성하고 실행하는 방법을 익힐 수 있었음
- 처음에는 어려운 부분도 있었지만 직접 코드를 입력하고 결과를 확인하니 조금씩 이해할 수 있었음
- 앞으로도 반복해서 연습하며 파이썬 기초 문법을 더 익히고 싶다는 생각이 들었음
