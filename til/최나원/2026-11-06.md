
## 1. 오늘 배운 것

- 서버는 인터넷에 연결되어 다른 사람들이 접속할 수 있도록 서비스를 제공하는 컴퓨터이다. 내 컴퓨터에서 실행한 서비스는 컴퓨터를 끄면 사용할 수 없지만, 서버에 올리면 인터넷을 통해 접속할 수 있다.
- 도메인은 인터넷에서 서버를 찾아가기 위한 주소이다.
- 포트는 서버에 접속할 때 사용하는 문 번호와 같다. 각 프로그램은 정해진 포트를 사용한다.
- HTTPS는 인터넷으로 주고받는 정보를 암호화하여 다른 사람이 쉽게 확인하지 못하도록 보호하는 통신 방식이다.
- 서버의 상태를 확인할 때 HTTP 상태 코드를 사용할 수 있다. 200은 요청이 정상적으로 처리되었다는 의미이다.
- 파이썬의 `urllib.request`를 사용하면 인터넷 주소에 요청을 보내고 서버의 응답을 확인할 수 있다.
- `socket`을 사용하면 특정 서버의 포트가 열려 있는지 확인할 수 있다.

## 2. 실습 문제 풀이

### 문제 1: 서버 상태 확인하기

```python
import urllib.request, json

url = "https://54-180-180-225.sslip.io/health"

with urllib.request.urlopen(url) as r:
    print(r.status, json.loads(r.read()))
```

`urllib.request`를 사용하여 서버에 요청을 보내는 코드이다. `r.status`는 서버의 응답 상태 코드를 확인하고, `json.loads()`는 서버에서 받은 JSON 데이터를 파이썬에서 사용할 수 있는 형태로 변환한다. 실행 결과는 `200 {'status': 'ok'}`이며, 서버가 정상적으로 작동하고 있다는 뜻이다.

### 문제 2: 서버 포트 확인하기

```python
import socket

def is_open(host, port):
    with socket.socket() as s:
        s.settimeout(3)
        return s.connect_ex((host, port)) == 0

host = "54-180-180-225.sslip.io"

print({port: is_open(host, port) for port in (443, 5432, 8000)})
```

`socket`을 사용하여 서버의 포트가 열려 있는지 확인하는 코드이다. `is_open()` 함수는 서버 주소와 포트 번호를 전달받아 연결이 가능한지 확인한다. `connect_ex()`의 결과가 0이면 연결이 가능하다는 뜻이다.

실행 결과는 다음과 같다.

```python
{443: True, 5432: False, 8000: False}
```

443 포트는 열려 있고, 5432와 8000 포트는 닫혀 있다는 것을 확인할 수 있다.

## 3. 어려웠던 것

서버와 포트의 차이를 이해하는 것이 처음에는 조금 어려웠다. 서버는 서비스를 제공하는 컴퓨터이고, 포트는 해당 컴퓨터에서 프로그램과 연결되는 문 번호라는 점을 정리하면서 이해했다. 또한 `urllib.request`와 `socket`이 각각 서버의 상태와 포트 연결 여부를 확인하는 데 사용된다는 차이도 알게 되었다.

## 4. 느낀점

이번 시간에는 내 컴퓨터에서 실행하는 프로그램과 인터넷에 연결된 서버의 차이를 배웠다. 특히 파이썬으로 직접 서버의 상태와 포트가 열려 있는지 확인할 수 있다는 점이 흥미로웠다. 이전에 배웠던 함수, 딕셔너리, 컴프리헨션도 실제 서버 상태를 확인하는 코드에 활용된다는 것을 알게 되었다. 앞으로도 지금까지 배운 파이썬 문법을 실제 프로젝트와 연결하여 이해하고 활용할 수 있도록 노력해야겠다고 느꼈다.
