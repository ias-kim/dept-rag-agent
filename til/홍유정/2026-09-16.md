## 1. 오늘 배운 것

- Python에서는 변수에 값을 저장하고 `type()`을 이용해 자료형을 확인할 수 있다는 것을 배웠다.
- `if`, `elif`, `else`를 사용하면 조건에 따라 실행할 코드를 나눌 수 있다는 것을 배웠다.
- `while`은 조건이 참인 동안 반복하고, `for`는 정해진 범위나 대상을 반복할 때 사용한다는 것을 배웠다.

## 2. 어려웠던 것

- `=`와 `==`의 차이가 처음에는 헷갈렸다.
- `int()`로 실수를 정수로 변환하면 소수점 이하가 어떻게 처리되는지 헷갈렸다.

## 3. 해결책 또는 시도한 것

직접 코드를 실행해서 자료형이 어떻게 바뀌는지 확인해 보았다.

```python
a = 7
b = 2.5

print(type(a))
print(type(b))

print(a + b)
print(type(a + b))

print(int(b))
print(str(a))
```

실행해 보니 `a + b`의 결과는 `9.5`이고 자료형은 `float`이 되었다.

또 `int(2.5)`의 결과가 `2`가 되는 것을 확인하면서 `int()`를 사용하면 소수점 이하가 버려진다는 것을 알게 되었다.

## 4. 느낀점

설명만 들을 때보다 직접 코드를 입력하고 실행 결과를 확인하니 Python의 자료형과 문법을 이해하기 쉬웠다.
