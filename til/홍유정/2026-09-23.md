## 1. 리스트(list)

리스트는 여러 개의 값을 순서대로 저장할 때 사용하는 자료형이다.  
값을 추가하거나 삭제할 수 있으며, 인덱스를 이용해 원하는 값에 접근할 수 있다.

```python
scores = [85, 92, 78]

print(scores[0])

scores.append(90)

print(scores)
print(len(scores))
```

또한 `for`문과 함께 사용하면 리스트의 값을 하나씩 꺼내서 사용할 수 있다.

```python
for score in scores:
    print(score)
```

---

## 2. 튜플(tuple)

튜플은 리스트처럼 여러 값을 순서대로 저장할 수 있지만, 한 번 만든 뒤에는 값을 변경할 수 없다.

```python
point = (3, 5)

print(point[0])
```

```python
point[0] = 10
```

위 코드는 튜플의 값을 변경하려고 했기 때문에 오류가 발생한다.

따라서 좌표처럼 값이 바뀌면 안 되는 데이터를 저장할 때 사용할 수 있다.

---

## 3. 딕셔너리(dict)

딕셔너리는 `key`와 `value`를 한 쌍으로 저장하는 자료형이다.

리스트가 번호로 값을 찾는다면, 딕셔너리는 이름을 이용해서 값을 찾을 수 있다.

```python
student = {
    "name": "홍유정",
    "grade": 1
}

print(student["name"])

student["track"] = "AI"

print(student)
```

딕셔너리는 각 값이 어떤 의미인지 알기 쉽다는 장점이 있다.

---

## 4. 집합(set)

집합은 중복된 값을 저장하지 않는 자료형이다.

```python
numbers = {1, 2, 2, 3}

print(numbers)
```

실행 결과:

```text
{1, 2, 3}
```

또한 두 집합의 공통 값을 구하는 교집합 연산도 할 수 있다.

```python
a = {"AI", "DB"}
b = {"DB", "WEB"}

print(a & b)
```

실행 결과:

```text
{'DB'}
```

---

## 5. 자료형 비교

- 리스트: 순서가 있고 값을 추가하거나 수정할 수 있을 때
- 튜플: 순서가 있지만 값이 변경되면 안 될 때
- 딕셔너리: 이름(key)을 이용해서 값을 찾고 싶을 때
- 집합: 중복을 제거하거나 두 데이터의 공통 값을 찾을 때

---

## 실습 1

과목 3개의 이름과 점수를 딕셔너리로 저장하고, 과목과 점수를 출력한 뒤 평균을 구했다.

```python
scores = {
    "Python": 90,
    "Java": 85,
    "Database": 95
}

total = 0

for subject, score in scores.items():
    print(subject, ":", score)
    total += score

average = total / len(scores)

print("평균:", average)
```

## 실습 2

리스트의 중복 값을 집합을 이용해 제거한 뒤 값의 개수를 구했다.

```python
numbers = [1, 2, 2, 3, 3, 3]

unique_numbers = set(numbers)

print(unique_numbers)
print(len(unique_numbers))
```

실행 결과:

```text
{1, 2, 3}
3
```

## 어려웠던 점

리스트, 튜플, 딕셔너리, 집합이 모두 여러 값을 저장하는 자료형이라 처음에는 각각 언제 사용해야 하는지 구분하는 것이 어려웠다. 직접 예제와 실습 문제를 풀어 보면서 자료형마다 값을 저장하고 사용하는 방식이 다르다는 것을 이해할 수 있었다.
