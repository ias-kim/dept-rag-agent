# 2026-10-21 TIL

## 1. 오늘 배운 것

- 파이썬의 예외처리는 프로그램 실행 중 오류가 발생했을 때 무조건 종료하는 대신, 오류 종류에 따라 처리 방법을 지정하는 문법이라는 것을 배움.
  - `try`에는 오류가 발생할 수 있는 코드를 작성하고, `except`에는 해당 오류가 발생했을 때 실행할 코드를 작성함.
  - `ValueError`는 문자열을 정수로 변환할 수 없는 경우 등에 발생하며, `except ValueError`로 처리하면 잘못된 입력을 건너뛰고 다음 작업을 진행할 수 있음.
  - `finally`는 오류 발생 여부와 관계없이 실행되고, `raise`는 정해진 조건을 위반했을 때 직접 예외를 발생시키는 데 사용함.
- 컴프리헨션은 반복문과 조건문을 활용해 새로운 리스트, 딕셔너리, 집합을 간결하게 생성하는 문법이라는 것을 배움.
  - `[s for s in scores if s >= 60]`은 점수 목록에서 60점 이상인 값만 선택하는 리스트 컴프리헨션임.
  - `{s: ("PASS" if s >= 60 else "FAIL") for s in scores}`는 각 점수를 키로, 합격 여부를 값으로 저장하는 딕셔너리 컴프리헨션임.
  - 기존 `for`문과 결과는 같지만 코드가 짧아지고, 어떤 데이터를 선택하거나 변환하는지 한눈에 파악하기 쉬워짐.
- `with open()`을 활용한 파일 입출력 방법도 학습함.
  - `with open("scores.txt", encoding="utf-8") as f:`로 파일을 열면 작업이 끝났을 때 자동으로 닫히므로 파일을 안전하게 관리할 수 있음.
  - `read().splitlines()`를 활용하면 텍스트 파일을 줄 단위의 리스트로 변환할 수 있음.
- 2~4주차에 배운 함수·클래스·`dataclass`와 이번 주 예외처리·컴프리헨션을 결합해 전공 자료 정리 스크립트를 작성하는 방법을 배움.
  - `Path(root).iterdir()`로 과목 폴더를 확인하고 `glob("*.pdf")`로 PDF 파일을 찾음.
  - `@dataclass`로 과목 코드와 파일 목록을 관리하는 `Course` 클래스를 정의하고, `summary()` 메서드로 과목별 자료를 정리함.
  - 폴더가 존재하지 않을 때는 `FileNotFoundError`를 처리해 프로그램이 종료되지 않도록 함.

## 2. 어려웠던 것

- `try·except·finally`의 실행 순서를 이해하는 것이 처음에는 헷갈렸음. 특히 `except`는 예외가 발생했을 때만 실행되지만 `finally`는 정상 실행 시에도 동작한다는 차이를 구분할 필요가 있었음.
- 컴프리헨션은 일반적인 `for`문보다 코드가 짧지만, 반복 대상과 조건식의 순서를 파악하는 데 시간이 걸렸음. 딕셔너리 컴프리헨션에서는 키와 값에 해당하는 표현식까지 함께 작성해야 해서 리스트 컴프리헨션보다 복잡하게 느껴졌음.
- 자료 정리 스크립트에서는 `Path`, `glob`, `dataclass` 등 여러 문법이 결합되어 있어 각각의 코드가 어떤 역할을 하는지 이해하기 어려웠음. 특히 폴더를 탐색하는 부분과 파일 이름을 추출하는 부분을 구분하는 것이 필요했음.

## 3. 해결책 또는 시도한 것

- 예외처리를 이해하기 위해 숫자로 변환할 수 없는 문자열을 입력하는 예제를 살펴보고, `try`에서 오류가 발생하면 `except`로 이동하는 과정을 확인함. `finally`를 추가해 오류 발생 여부와 관계없이 마지막 코드가 실행되는 구조도 정리함.
- 컴프리헨션은 먼저 일반 `for`문으로 작성한 뒤 동일한 작업을 한 줄로 변환하는 방식으로 비교함.
  - `[s for s in scores if s >= 60]`을 `담을 값 → 반복 대상 → 조건` 순서로 나누어 읽으니 구조를 이해하기 쉬웠음.
  - 딕셔너리 컴프리헨션은 `{키: 값 for 변수 in 목록}` 구조를 기준으로 PASS/FAIL 판별식을 추가하는 방법으로 정리함.
- 점수 파일 처리 실습에서는 `with open()`으로 파일을 읽고, 각 줄을 `int()`로 변환하되 숫자가 아닌 줄은 `except ValueError`에서 제외하도록 코드를 구성함. 정상적으로 변환된 점수만 평균 계산에 사용하고 제외한 줄의 개수도 별도로 세도록 함.
- 자료 정리 스크립트는 기존에 PDF 개수를 출력하던 `summary()` 메서드를 수정해, `self.files`에 저장된 파일 이름을 `", ".join(self.files)`로 연결하여 출력하도록 구성함. 이를 통해 클래스에 저장된 데이터를 원하는 형식으로 가공하는 방법을 복습함.

## 4. 느낀점

- 이전에 배운 함수와 클래스가 각각 독립적인 개념처럼 느껴졌는데, 이번 주 자료 정리 스크립트에서는 여러 문법이 하나의 프로그램 안에서 연결되는 과정을 볼 수 있어 의미 있었음.
- 특히 예외처리는 단순히 오류를 막는 문법이 아니라, 예상하지 못한 입력이나 파일 문제에도 프로그램이 안정적으로 동작하도록 만드는 중요한 기능이라는 것을 알게 됨.
- 컴프리헨션은 아직 일반 반복문보다 익숙하지 않지만, 기존 코드를 직접 변환하는 연습을 반복하면 복잡한 코드도 더 간결하게 작성할 수 있을 것 같음.
- 앞으로는 새로운 문법을 외우는 것뿐 아니라 실제 프로그램에서 어떤 문제를 해결하기 위해 사용하는지 생각하면서 공부해야겠다고 느낌.
