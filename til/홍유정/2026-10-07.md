## 1. 학습 내용

### 1) 함수(def)와 return

함수는 반복해서 사용하는 코드를 하나로 묶어 필요할 때 호출하는 기능이다.

- `def`: 함수를 정의할 때 사용한다.
- `return`: 함수의 실행 결과를 반환한다.

```python
def average(scores):
    return sum(scores) / len(scores)

print(average([85, 92, 78]))
```

실행 결과: `85.0`

### 2) 매개변수와 기본값

매개변수는 함수에 전달하는 값이며, 기본값을 지정하면 인자를 생략했을 때 기본값이 사용된다.

```python
def greet(name, title="학생"):
    return f"{name} {title}님"

print(greet("유정"))
```

실행 결과: `유정 학생님`

### 3) 모듈과 import

모듈은 함수나 변수 등을 별도의 파이썬 파일에 저장한 것이다. `import`를 사용하면 다른 파일의 기능을 가져올 수 있다.

```python
import math

print(math.sqrt(16))
```

실행 결과: `4.0`

## 2. 실습 문제

### 문제 1. 점수 리스트의 최댓값과 평균 구하기

```python
def score_info(scores):
    max_score = max(scores)
    avg_score = sum(scores) / len(scores)
    return max_score, avg_score

scores = [85, 92, 78]
print(score_info(scores))
```

실행 결과: `(92, 85.0)`

### 문제 2. 함수를 별도 모듈로 분리하기

**my_utils.py**

```python
def score_info(scores):
    return max(scores), sum(scores) / len(scores)
```

**main.py**

```python
from my_utils import score_info

scores = [85, 92, 78]
print(score_info(scores))
```

실행 결과: `(92, 85.0)`
