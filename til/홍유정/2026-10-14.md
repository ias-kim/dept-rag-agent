## 1. 오늘 배운 것

- 이번 4주차 튜터링에서는 파이썬의 객체지향 프로그래밍(OOP)을 중심으로 클래스와 객체, 생성자(`__init__`), 메서드, 상속, `dataclass`의 개념과 사용 방법을 학습함.
- 지난 3주차에는 함수와 모듈을 이용해 코드를 기능별로 분리하는 방법을 배웠다면, 이번에는 서로 관련된 데이터와 기능을 하나의 클래스로 묶어 관리하는 방법을 배움.
- **클래스(Class)**는 객체를 생성하기 위한 설계도이고, **객체(Object)**는 해당 클래스를 바탕으로 실제 생성된 인스턴스라는 것을 이해함. 예를 들어 `Student` 클래스를 정의하면 학생마다 이름과 학년이 다른 여러 객체를 생성할 수 있음.
- `__init__()`은 객체가 생성될 때 초기값을 설정하는 메서드이며, `self`는 생성된 객체 자기 자신을 가리킴. `self.name = name`과 같이 작성하면 전달받은 이름을 객체의 속성으로 저장할 수 있고, 다른 메서드에서도 `self.name`으로 접근할 수 있음.
- 클래스 내부에 정의된 함수를 **메서드(Method)**라고 하며, 일반 함수와 달리 객체가 가지고 있는 데이터에 접근하여 동작을 수행할 수 있다는 점을 배움. 예를 들어 `Student` 클래스의 `introduce()` 메서드는 객체에 저장된 이름과 학년을 이용해 자기소개 문자열을 반환함.
- **상속(Inheritance)**은 기존 클래스의 속성과 메서드를 새로운 클래스에서 재사용하는 기능임. `class Tutor(Student):`와 같이 작성하면 `Tutor` 클래스가 `Student` 클래스의 기능을 물려받을 수 있음.
- 부모 클래스의 메서드를 자식 클래스에서 같은 이름으로 다시 정의하는 것을 **메서드 오버라이딩(Overriding)**이라고 함. 이를 이용하면 기존 기능을 유지하면서도 필요한 동작만 변경할 수 있음.
- **`dataclass`**는 데이터를 저장하는 목적의 클래스를 간결하게 작성할 수 있도록 도와주는 기능임. `@dataclass`를 사용하면 `__init__()` 등을 자동으로 생성해 주기 때문에 반복되는 코드를 줄일 수 있음.
- `@dataclass(frozen=True)`로 선언하면 객체를 생성한 뒤 속성값을 다시 대입하여 변경하는 것을 막을 수 있음. 튜터링 프로젝트에서도 검색 도구와 안내 메시지를 하나로 묶어 전달하는 `Plan` 클래스에 이러한 방식이 사용된다는 점을 알게 됨.
- 이번 주 프로젝트에서는 사용자의 질문을 분석하여 학사 공지 검색(`academic`), 전공 자료 검색(`major`), 두 검색 모두 사용(`both`), 범위 밖 질문(`none`)의 네 가지로 분류하는 라우터를 구현하였음.
- 질문의 종류는 AI 모델이 판단하지만, 실제 어떤 검색 도구를 실행할지는 프로그램이 학생의 수강 정보를 확인한 뒤 결정하도록 설계함. 이를 통해 AI의 판단과 자료 접근 권한을 결정하는 프로그램의 역할을 분리할 수 있다는 것을 이해함.
- 라우터 도입 전에는 검색 도구를 총 72회 호출했지만, 2차 개선 이후에는 38회로 감소하였고 답변 정확도는 기존과 동일한 91.7%를 유지함. 새로운 기능을 구현할 때 단순히 동작 여부만 확인하는 것이 아니라 정확도와 효율을 함께 평가해야 한다는 점을 배움.

## 2. 어려웠던 것

- 처음에는 클래스와 객체의 개념이 비슷하게 느껴져 둘의 차이를 명확하게 구분하기 어려웠음. 특히 클래스를 정의하는 것과 실제 객체를 생성하는 것이 어떤 차이인지 이해하는 데 시간이 필요했음.
- `__init__()`의 역할과 `self`를 사용하는 이유가 헷갈렸음. 일반 함수에서는 매개변수를 통해 값을 전달받는데, 클래스 내부에서는 왜 `self`를 첫 번째 매개변수로 작성해야 하는지 이해하기 어려웠음.
- `self.name = name`처럼 왼쪽과 오른쪽에 비슷한 이름이 사용되지만, 왼쪽은 객체의 속성이고 오른쪽은 메서드에 전달된 매개변수라는 차이를 구분해야 했음.
- 상속을 사용하면 부모 클래스의 기능을 자식 클래스에서도 사용할 수 있다는 것은 이해했지만, 자식 클래스에서 메서드를 다시 정의했을 때 어떤 메서드가 실행되는지 헷갈렸음.
- 일반 클래스와 `dataclass`가 어떤 차이가 있는지, 각각 어떤 상황에서 사용하는 것이 적절한지 판단하기 어려웠음.
- 실습 문제에서 과목 이름과 여러 점수를 하나의 객체에 저장하고, 저장된 점수 목록을 이용하여 평균을 계산하는 메서드를 작성하는 과정이 어려웠음.
- 특히 평균을 구하는 기능은 부모 클래스에 작성하고, 평균에 따른 합격 여부를 판단하는 기능은 자식 클래스에 추가하는 구조를 생각하는 데 어려움이 있었음.

## 3. 해결책 또는 시도한 것

- 클래스와 객체의 차이를 이해하기 위해 클래스를 설계도, 객체를 설계도로 만든 실제 물건에 비유하여 정리함. 같은 클래스에서 여러 객체를 생성하더라도 각 객체는 서로 다른 데이터를 저장할 수 있다는 점을 예제 코드로 살펴봄.
- `__init__()`과 `self`의 역할을 이해하기 위해 `Student` 클래스를 직접 작성하고, 이름과 학년이 다른 객체를 생성하여 각각의 속성과 메서드가 어떻게 동작하는지 확인하는 방식으로 학습함.
- 상속은 부모 클래스의 기능을 그대로 활용하면서 자식 클래스에 새로운 기능을 추가할 수 있다는 점에 집중하여 이해하고자 함.
- `dataclass`는 일반 클래스와 달리 생성자 등을 직접 작성하지 않아도 된다는 특징을 비교하면서, 값만 저장하는 클래스에 유용하다는 점을 정리함.

**실습 문제 1. Course 클래스 만들기**

과목 이름과 점수 목록을 저장하는 `Course` 클래스를 만들고, `average()` 메서드를 이용해 점수의 평균을 반환하도록 작성함.

```python
class Course:
    def __init__(self, name, scores):
        self.name = name
        self.scores = scores

    def average(self):
        return sum(self.scores) / len(self.scores)


course1 = Course("Python", [80, 90, 70])

print(course1.name)
print(course1.average())
```

**예상 실행 결과**

```text
Python
80.0
```

- `__init__()`을 이용해 객체가 생성될 때 과목 이름과 점수 목록을 저장하도록 함.
- `self.name`에는 과목 이름을, `self.scores`에는 여러 점수가 들어 있는 리스트를 저장함.
- `sum()`을 이용해 점수의 총합을 구하고, `len()`으로 점수의 개수를 구한 다음 나누어 평균을 계산함.
- `course1.average()`를 호출하면 객체에 저장된 점수 목록을 바탕으로 평균값을 반환함.
- 이를 통해 클래스 내부에 데이터를 저장하고 메서드에서 해당 데이터를 활용하는 구조를 이해할 수 있었음.

**실습 문제 2. PassFailCourse 클래스 만들기**

기존 `Course` 클래스를 상속받는 `PassFailCourse` 클래스를 만들고, 평균이 60점 이상이면 `"PASS"`, 60점 미만이면 `"FAIL"`을 반환하도록 작성함.

```python
class PassFailCourse(Course):
    def pass_status(self):
        if self.average() >= 60:
            return "PASS"
        else:
            return "FAIL"


course2 = PassFailCourse("Java", [70, 80, 90])
course3 = PassFailCourse("Database", [40, 50, 60])

print(course2.name, course2.average(), course2.pass_status())
print(course3.name, course3.average(), course3.pass_status())
```

**예상 실행 결과**

```text
Java 80.0 PASS
Database 50.0 FAIL
```

- `class PassFailCourse(Course):`로 작성하여 기존 `Course` 클래스를 상속받도록 함.
- 자식 클래스에서는 별도로 `__init__()`을 작성하지 않아도 부모 클래스의 생성자를 사용할 수 있음.
- 부모 클래스에 이미 정의된 `average()` 메서드를 재사용하여 중복된 평균 계산 코드를 작성하지 않도록 함.
- `pass_status()` 메서드에서 `self.average()`를 호출해 평균을 구하고, 조건문을 이용해 합격 여부를 판단하도록 구현함.
- 평균 계산 방식이 변경되더라도 부모 클래스의 메서드만 수정하면 자식 클래스에도 적용할 수 있다는 점에서 상속의 장점을 이해함.

이번 실습을 통해 기존에 학습한 리스트, 함수, 조건문을 클래스와 결합하여 사용할 수 있다는 점을 확인할 수 있었음. 또한 상속을 활용하면 비슷한 기능을 반복해서 작성하지 않고 기존 코드를 재사용할 수 있다는 것을 알게 됨.
